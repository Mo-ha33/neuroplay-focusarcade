# Demo Files for Live Upload Testing

These files are pre-configured for the 4-minute hackathon demo to showcase the Universal File Ingestion feature.

## Usage During Demo

### Teacher Portal Demo
1. Log in as **Ms. Rodriguez** (Teacher)
2. Drag `sample_curriculum.txt` onto the "AI Curriculum Ingestion Engine" dropzone
3. Watch the AI processing animation
4. See the "3 Focus Quests Generated!" success state
5. Click "Assign to Students" button

### Parent Portal Demo
1. Log in as **David Kim** (Parent)
2. Drag `sample_iep_report.txt` onto the "Clinical & IEP Document Upload" zone
3. Watch the AI parameter tuning animation
4. See the adaptive difficulty badges appear

### Student Portal Demo
1. Log in as **Aiden Carter** (Student)
2. Take a screenshot or use any image file
3. Drag it onto the "Space Scanner Station"
4. Watch the confetti explosion and "+50 Space XP!" reward

## File Descriptions

| File | Portal | Purpose |
|------|--------|---------|
| `sample_curriculum.txt` | Teacher | Solar System STEM curriculum for AI quest generation |
| `sample_iep_report.txt` | Parent | IEP clinical recommendations for difficulty tuning |
| Any `.png`/`.jpg` image | Student | Homework scan for instant XP reward |
